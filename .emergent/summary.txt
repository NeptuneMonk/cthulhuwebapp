**Key Technical Concepts**
*   **Client-Side Signing (PSBT):** The core security model. Transactions are built as Partially Signed Bitcoin Transactions (PSBTs) on the frontend, signed with the user's key, and the final hex is sent to the backend for broadcast only.
*   **bitcoinjs-lib:** The primary library used on the frontend for all Bitcoin-related operations, including key management, address generation, and transaction construction (PSBT).
*   **@noble/secp256k1:** A pure JavaScript cryptographic library used for elliptic curve operations, replacing a WASM-based alternative to ensure browser compatibility.
*   **Web Crypto API:** Used to encrypt and decrypt the user's wallet private key (WIF) in the browser using a key derived from their password.
*   **IPFS Kubo Daemon:** A local IPFS node running on the backend server, used for all file uploads to ensure content is pinned within the application's ecosystem, mirroring the SUP architecture.
*   **IndexedDB:** The chosen technology for the client-side IPFS cache.
